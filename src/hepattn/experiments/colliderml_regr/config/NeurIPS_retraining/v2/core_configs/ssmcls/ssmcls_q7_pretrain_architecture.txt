  ======================== Training setup ========================

  Optimizer        : Lion
  Weight decay     : 1e-3
  Schedule         : OneCycle  pct_start=0.10
                       initial = 1.0e-05
                       peak    = 5.0e-05
                       end     = 1.0e-06
  Precision        : 32-true (bf16 autocast only inside encoder)
  Gradient clip    : 1.0
  Epochs           : 50        EarlyStop patience=50 on val/total
  Device           : 1x H100 (trainer.devices=[0])
  Resume from ckpt : 3fc8acb5/epoch=015-val_total=0.01108.ckpt

  Data             : /scratch/colliderml/p0_core_pretrain
                     batch_size 2048, num_workers 16
                     load_acts=true on val loader -> DM metrics active
                     train loader hard-coded load_acts=False (free for train)

  ========================== Notes ===============================

  Stability fixes applied (do not regress):
   * CLS extracted from gated+residualised output (mamba_cls.py)
     -> same gate + residual path as hit tokens.
   * pool_head Dense bottleneck (Linear(2*dim, state_head_output_dim))
     -> prevents raw encoder-output gradients entering bf16 backward
     at ~7x higher magnitude.
   * output_head_init_scale = 0.01 keeps initial predictions near 0.
   * Encoder dropout = 0.0 (matches the working ssm_q7 config).
   * GradientSpikeSkip removed (root-cause fix in place).
