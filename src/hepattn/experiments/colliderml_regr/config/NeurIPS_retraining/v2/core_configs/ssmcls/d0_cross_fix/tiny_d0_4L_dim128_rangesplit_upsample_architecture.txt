  ======================== Diagnostic intent =====================

  Single-axis ablation vs rangesplit run 97f8a4a8 (which showed a
  residual d0=0 cross). Tests whether the cross comes from router
  bias under natural 95/5 class imbalance rather than from the
  3-head architecture. If cross lifts here, single-encoder range-split
  is sufficient and the twin-encoder variant is not needed.
