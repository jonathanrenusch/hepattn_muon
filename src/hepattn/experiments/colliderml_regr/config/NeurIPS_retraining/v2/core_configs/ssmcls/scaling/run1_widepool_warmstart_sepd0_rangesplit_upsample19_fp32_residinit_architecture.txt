  ==================== What this config tests ====================

  * separate-d0 architecture (DFL/CE-style branch off the shared encoder)
    + d0_grad_scale=0.0005 (effectively isolates d0 from shared trunk
    gradient updates) + range-split classifier
        ----> the validated d0-cross fix (run da4a7697 was tiny version)
    delivered at scaled capacity (15 L / d_state=64) with proper
    fp32 + residual-depth init regularization.

  * pool_head removed entirely (Identity) — both branches consume the
    raw (B, 384) CLS concat, no learned squeeze, no impedance match
    (not needed under fp32).

  * Loss balance: d0 and phi de-weighted to 0.1 (already strong heads);
    z0/theta/qop equal-weighted at 1.0 (lets z0/theta/qop steer trunk
    capacity toward where the core-resolution gap still lives).

  * Per-parameter grad logging tells us whether late-training
    output_head spikes are concentrated on a single physics parameter
    -> first-step diagnostic for whether d0_grad_scale=0.0005 needs
    tuning (still too leaky?  too aggressive?).
